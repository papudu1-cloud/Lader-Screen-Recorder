# Mapa de arquivos

- `index.html`: página inicial.
- `Iniciar/Styles/CSS/style.css`: interface.
- `Iniciar/Styles/JS/recorder.js`: captura, gravação, pré-visualização e download.
- `Iniciar/PNG/lader-screen-recorder.svg`: logótipo vetorial (SVG, não PNG).
- `Iniciar/SYSTEMS/CONFIG/config.config`: configuração do projeto.
- `Iniciar/SYSTEMS/OPTION/option.option`: opções do projeto.
- `Iniciar/SYSTEMS/INI/settings.ini`: definições INI.
- `Iniciar/SYSTEMS/MUI/system.mui`: mapa do sistema.

Os formatos CS, PS1, CMD, BAT, PY, PYW, JSW e EXE não são necessários para a versão web funcional. Não foram criados executáveis ou scripts auxiliares que não tenham uma função real nesta versão.
